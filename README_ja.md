## 使用方法

1. 圧縮ファイルをダウンロードし、展開します
2. **ランワン.exe** をダブルクリックしてプログラムを起動します
3. **リストを更新** ボタンをクリックして最新のサーバーリストを取得します
4. **順番に接続** ボタンをクリックして、サーバーリストにあるサーバーに順番に接続します
5. 初回接続時には、L2TP/IPsecに必要なセキュリティパラメータを設定するために**管理者権限**が要求されます
