## Usage Instructions

1. Download and extract the compressed package
2. Double-click **LanWan.exe** to start the program
3. Click the **Refresh List** button to obtain the latest server list
4. Click the **Connect in Order** button to connect to the servers in the list one by one
5. The first connection will request **administrator privileges** to configure the security parameters required for L2TP/IPsec
