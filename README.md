## 🚀 使用方法

1. 无需安装，双击“蓝湾.exe”启动程序
2. 点击「刷新列表」获取服务器列表
3. 点击「顺序连接」对服务器列表中的服务器依次进行测试连接

### 提示

- 首次运行需要获取管理员权限配置安全参数
