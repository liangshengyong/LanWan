## 使用方法

- 点击 [这里](https://github.com/liangshengyong/LanWan/releases/latest) 下载最新版本
1. 压缩包解压后，双击 蓝湾.exe 启动程序
2. 点击「刷新列表」获取最新服务器列表
3. 点击「顺序连接」对服务器列表中的服务器依次进行连接
- 首次运行需要获取管理员权限配置安全参数
