# 蓝湾

是一个 L2TP/IPsec 服务器测试程序。

## 🚀 Usage

### 下载

- 直接下载 `蓝湾.exe`
- 无需安装，双击运行

### 使用说明

1. 启动程序
2. 点击「刷新列表」获取服务器列表
3. 点击「顺序连接」对服务器列表依次进行测试连接
